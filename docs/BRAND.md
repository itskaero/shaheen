# Shaheen Brand System

## Core identity

Name: Shaheen
Country: Pakistan
Game: Brawlhalla

Primary motto:
بلندیوں کی جانب

English:
Higher Together

Secondary:
From Pakistan to the Arena.

## Visual direction

Primary palette:
- deep forest green
- emerald
- gold
- black
- cream

Motifs:
- shaheen/falcon
- crescent and star
- flight/elevation
- arena/esports
- restrained Pakistani architectural references

Avoid:
- excessive neon
- generic gamer clichés
- rainbow role colors
- excessive emojis
- childish copy
- cluttered embeds

## Urdu

Discord cannot reliably force a custom Urdu font across all clients.
Use Unicode Urdu for text and reserve special Nastaliq typography for images,
logos and designed banners.

## Embed style

Use:
- short headings
- clear hierarchy
- restrained emoji
- green/gold visual identity
- useful buttons
- concise copy

The bot should feel like one branded Shaheen system.
