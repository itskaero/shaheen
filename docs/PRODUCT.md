# Product Definition

## Identity

Shaheen is a Pakistan-based Brawlhalla clan.

The identity is built around the shaheen/falcon: ambition, skill, discipline,
freedom and rising above.

Primary motto:

**بلندیوں کی جانب — Higher Together**

Secondary concept:

**From Pakistan to the Arena.**

## Current state

The project is private/in-development. There is initially one member.

Do not optimize for a large public community before the core experience works.

## Product principles

- Clean rather than bloated
- Esports-oriented rather than corporate
- Pakistani identity without excluding international players
- English-first with selective Urdu
- Automation should reduce administration
- Data should be reusable by the future website
- Avoid "card soup", excessive emojis and generic gamer aesthetics

## Future ecosystem

Discord is the community/interface.
Shaheen Bot is the Discord/backend automation layer.
The future website is the public identity/statistics layer.
Brawlhalla API is an external data source.
The Shaheen database is the persistent source for clan-specific history.
